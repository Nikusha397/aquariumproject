# Aquarium Project

A web project focused on aquarium products and information. The goal was to build a clean and easy-to-use interface where users can browse the available content and explore different sections of the site.

## Tech Stack

Add the technologies used in this project.

## Getting Started

Clone the repository, install the dependencies, and run the development server.

```bash
npm install
npm run dev
```

Open the local URL shown in your terminal to view the project.
